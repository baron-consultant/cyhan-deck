# Dual Wide Slidev Deck

This deck is configured from `듀얼용.pptx`.

- Reference PPTX size: approximately `26.668in x 7.5in`
- Slide ratio: `32:9`
- Slidev canvas: `8000 x 2250 px`

## Commands

```sh
npm install
npm run dev
npm run dev:remote
npm run export:pptx
npm run export:pdf
npm run export:png
```

The main settings live in the first frontmatter block of `slides.md`:

```yaml
aspectRatio: 32/9
canvasWidth: 8000
```
